# מדריך עברי++ 0.2.0

## הרעיון
עברי++ היא שכבת כתיבה מעל C++17. מילות מפתח מתורגמות באמצעות מאקרואים, וטיפוסים ופעולות STL נחשפים דרך namespace בשם `עברי`.

## התחלה
```cpp
#include <ivri/ivri.hpp>
שלם ראשי() {
    עברי::וקטור<שלם> מספרים = {3, 1, 2};
    עברי::מיין(מספרים);
    עברי::הדפס_וקטור(מספרים);
    החזר 0;
}
```

## מילון בסיסי
| עברית | C++ | משמעות |
|---|---|---|
| `שלם` | `int` | מספר שלם |
| `ממשי` | `float` | מספר נקודה צפה |
| `כפול` | `double` | דיוק כפול |
| `לוגי` | `bool` | אמת/שקר |
| `אם` | `if` | תנאי |
| `אחרת` | `else` | הסתעפות |
| `עבור` | `for` | לולאה |
| `כלעוד` | `while` | לולאה מותנית |
| `החזר` | `return` | החזרת ערך |
| `מחלקה` | `class` | הגדרת מחלקה |
| `עברי::וקטור<T>` | `std::vector<T>` | מערך דינמי |
| `עברי::מפה<K,V>` | `std::map<K,V>` | מפת מפתחות וערכים |
| `עברי::הוסף(v,x)` | `v.push_back(x)` | הוספת איבר |
| `עברי::מיין(v)` | `std::sort(...)` | מיון בסדר עולה |
| `עברי::סכום(v)` | `std::accumulate(...)` | סכום איברים |

## קומפילציה
מתיקיית השורש:
```bash
cmake -S . -B build
cmake --build build --config Release
cmake -E chdir build ctest -C Release --output-on-failure
```
או ישירות:
```bash
g++ -std=c++17 -Iinclude examples/01_basics.cpp -o demo
./demo
```

## חיבור לפרויקט CMake

אם תיקיית עברי++ נמצאת בתוך הפרויקט, למשל ב־`vendor/ivri`, הוסיפו לקובץ ה־CMake שלכם את השורות הבאות אחרי הגדרת היעד `my_app`.

```cmake
add_subdirectory(vendor/ivri)
target_link_libraries(my_app PRIVATE Ivri::Ivri)
```

אפשר גם להתקין מקומית. הריצו את הפקודות הבאות מתיקיית עברי++.

```sh
cmake -S . -B build/install -DIVRI_BUILD_EXAMPLES=OFF
cmake --install build/install --prefix ./ivri-install
```

בפרויקט הצורך, הגדרו את הנתיב המלא של `ivri-install` ב־`CMAKE_PREFIX_PATH` בזמן ה־configure והוסיפו ל־CMake את השורות הבאות.

```cmake
find_package(Ivri 0.2 CONFIG REQUIRED)
target_link_libraries(my_app PRIVATE Ivri::Ivri)
```

המאקרואים מופעלים בכל קובץ שבו כוללים את `<ivri/ivri.hpp>`. שמרו את קובצי המקור ב־UTF-8. בחיבור דרך CMake, היעד מוסיף את דגל `/utf-8` למהדר MSVC.

## מגבלות
* אי אפשר לתרגם `#include` ל־`#כלול` עם מאקרו רגיל.
* מאקרואים גלובליים עלולים להתנגש בשמות של קוד אחר. מומלץ לכלול את הכותרת אחרי כותרות C++ רגילות, ולהימנע משמות זהים למאקרואים בפרויקט.
* `עברי::מיין` תומכת כרגע בווקטורים עם השוואת `<` תקינה.
* מחרוזות בעברית מחייבות טרמינל וקידוד UTF-8 תקינים.
* הרחבות עתידיות יהיו מודולריות, כדי לא להעמיס את כל הספריות על כל קובץ.
