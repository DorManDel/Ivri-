# תוכנית עברי++

התוכנית המקורית התחילה בשחזור הכותרת והדוגמה המקיפה, בדיקת הידור, והעלאת README, דוגמאות ובדיקות. אחר כך הוצעה מעבדה דו־לשונית עם דוגמאות שאפשר להריץ, ובהמשך סביבת עריכה מוגבלת ומשוב על שגיאות.

| שלב | מצב |
| --- | --- |
| ספריית C++17, דוגמה מקיפה ומדריכים | פורסם ב־v0.2.0 |
| מסוף עברי עם פקודות וחיווי על קלט לא תקין | רץ מקומית ובדפדפן |
| השוואת עברי++ ל־C++ והרצת דוגמאות נבחרות | זמין דרך ה־[Playground](../playground/) |
| עריכת קוד והצגת שגיאות הידור | שלב המשך |
| ערכת התקנה ופתיחה בפקודה אחת, השלמה אוטומטית ותמיכת RTL בעורך | רעיונות להמשך |

התקנה באמצעות CMake כבר מתועדת ב[מדריך בעברית](GUIDE_HE.md).
