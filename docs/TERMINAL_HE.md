# המסוף העברי - מדריך

## הרצה

```bash
cmake -S . -B build
cmake --build build --config Release
./build/03_hebrew_terminal
```

ב־PowerShell עם Visual Studio, נתיב הקובץ אחרי בניית Release הוא `.\build\Release\03_hebrew_terminal.exe`. לקלט עברי אינטראקטיבי ב־Windows אפשר להריץ דרך WSL.

## פקודות

| פקודה | פעולה | דוגמה |
|---|---|---|
| `עזרה` | מציגה את הפקודות | `עזרה` |
| `שלום` | מדפיסה ברכה | `שלום` |
| `הוסף` | מוסיפה מספר שלם | `הוסף 42` |
| `הצג` | מציגה את הרשימה | `הצג` |
| `מיין` | ממיינת בסדר עולה | `מיין` |
| `חשב` | מחשבת סכום וממוצע | `חשב` |
| `נקה` | מנקה את הרשימה | `נקה` |
| `יציאה` | מסיימת את התוכנית | `יציאה` |

## מה לומדים?

- `מחלקה`, `פרטי`, `ציבורי`: מחלקת C++ עם שדות ומתודות.
- `כלעוד`, `אם`, `אחרת`, `עצור`, `המשך`: בקרת זרימה.
- `עברי::וקטור<שלם>`: `std::vector<int>` עם alias עברי.
- `עברי::הוסף`, `עברי::מיין`, `עברי::הדפס`: עטיפות לפונקציות C++.
- `std::getline` ו־`std::istringstream`: קריאת שורות ופענוח פקודות. אלו עדיין שמות אנגליים ונרחיב את המילון בהמשך.

## דוגמת שימוש

```text
עברי++> הוסף 10
המספר נוסף.
עברי++> הוסף 30
המספר נוסף.
עברי++> חשב
סכום: 40 | ממוצע: 20
עברי++> יציאה
להתראות!
```

## מגבלות

המסוף קורא וכותב טקסט ב־UTF-8. הצגת עברית לצד מספרים וסימני פיסוק תלויה בתמיכה בטקסט דו־כיווני (BiDi) של המסוף שבו הוא רץ.
