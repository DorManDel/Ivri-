# אב־הטיפוס של עברי++

התיקייה כוללת את הכותרת המקורית ואת הדוגמה המקיפה שלה. הדוגמה עוברת על וקטורים, מחלקות, מפות, אלגוריתמים, מתמטיקה וקבצים. הריצו אותה כתוכנית עצמאית עם הכותרת שבתיקייה הזו.

```sh
g++ -std=c++17 -Wall -Wextra -pedantic example_ivri.cpp -o ivri_demo
./ivri_demo
```

הדוגמה יוצרת קובץ בשם `ivri_output.txt` בתיקיית ההרצה. `החלף` משמש ל־`switch` ו־`החלף_ערכים` משמש ל־`std::swap`. הכינוי `מכיל` זמין החל מ־C++20 עבור מכולות שמספקות `contains`.
