# Playground של עברי++

המעבדה מציגה שתי דוגמאות מהריפו ומריצה את הקוד שלהן בדפדפן.

- **מיון וסכום** מריץ את `01_basics.cpp` ומציג פלט מיידי.
- **מסוף עברי** מריץ את `03_hebrew_terminal.cpp`. הדביקו פקודה בכל שורה ולחצו על **הרצה**. כל הרצה פותחת מסוף חדש.

בחלונית C++ מוחלפות מילות המפתח שהוגדרו ב־`core.hpp`. מזהים בעברית וקריאות לספריית `עברי` נשארים חלק מקוד ה־C++ שמוצג.

## בנייה מקומית

נדרשים Python 3 ו־Zig 0.15.2. משורש הריפו:

```sh
python3 playground/build.py
```

פתחו את `playground/dist/index.html` בדפדפן. אפשר לפתוח את הקובץ ישירות אחרי הבנייה. קובץ הנתונים שנוצר מכיל את קוד המקור ואת שתי הדוגמאות שהודרו ל־WebAssembly. אפשר להעביר ל־`--zig` נתיב למהדר ול־`--output` תיקיית פלט.
